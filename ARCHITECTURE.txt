API ROUTES
================================================================================

POST /api/device/advisory
  Input:  { device: DeviceIdentity, specs: DeviceSpecs | null, purpose: Purpose }
  Output: { purposeFit: PurposeFitResult, upgradeability, missingInformation, conflictWarnings[], confidence, generatedAt }
  Logic:  evaluatePurposeFit(specs, purpose, device.category)
          → detects smartphones via category or chip (A-series/Snapdragon/MediaTek/Exynos)
          → routes to evaluateSmartphone() or laptop/PC logic
          conflictDetectionEngine → detectConflicts()
          generateUpgradeability() + getMissingInformation()

POST /api/device/serial-lookup
  Rate limit: 10 req/min per IP
  Input:  { serialNumber: string, brand?: string }
  Output: SerialLookupResult — { device, specs, upgradeability, warranty, providerStatuses }
  Logic:  SerialProviderRegistry → tries Dell, HP, Lenovo, Apple, Samsung, Asus, Acer, Surface
  Note:   Serial number masked in all logs (maskSerial → "SN/****xxxx")
          Serial sent via POST body only — never in URL params

POST /api/product/analyse-link
  Rate limit: 10 req/min per IP (most expensive — fetches external URLs)

================================================================================
LIKE-FOR-LIKE MATCHING SYSTEM
================================================================================

Store matching (SerpApiStoreProvider):

  Query strategy:
    Primary: brand + model + CPU family + CPU number + RAM + storage
    Fallback: brand + model + CPU number only (runs when primary < 3 results)

  Score components:
    +25  brand match (or alias: "iphone" matches "apple")
    +20  model/series match
    +25  CPU model number match (e.g. "7520U")
    +15  CPU family match (e.g. "Ryzen 5")
    +15  RAM match
    +10  storage match
    +5   SSD/NVMe bonus
    -50  wrong brand detected
    -50  CPU architecture conflict (AMD vs Intel)
    -40  Ryzen tier conflict (Ryzen 3 vs Ryzen 5)
    -30  RAM mismatch
    -25  storage mismatch
    -30  variant suffix conflict ("Pro" / "Plus" / "Ultra" / "Max" / "Mini"
         following a digit — avoids "ProBook", "Core Ultra" false positives)
    -15  target has variant suffix but listing omits it

  Dynamic thresholds (phone-safe):
    maxPossible = 45 + (cpu?40:0) + (ram?15:0) + (storage?15:0)
    exactThreshold  = maxPossible>=85 ? 85 : round(maxPossible * 0.85)
    likelyThreshold = maxPossible>=65 ? 65 : round(maxPossible * 0.70)
    similarThreshold = maxPossible>=35 ? 35 : round(maxPossible * 0.45)
    score < 10 → rejected entirely

Review matching (reviewMatchEngine):

  classifyReviewResult(text, device, specs) → ReviewMatchType
    exactDevice:      brand + series + (CPU model OR CPU family OR phone storage GB)
    sameModelFamily:  brand + series only, or brand + CPU model (no series)
    differentVariant: CPU architecture conflict or Ryzen tier conflict
    unrelated:        no brand match, or accessory/forum content

  Phone exact-match rule:
    When cpuModel=null and cpuFamily=null (A-series, MediaTek etc.):
      storageGb in snippet (e.g. "512GB") → exactDevice

  buildReviewDeviceQuery(device, specs) → query string (max 70 chars)
    Uses: brand + model (without brand prefix) + CPU number (or family)
    Example: "HP 15s 7520U", "Apple iPhone 14", "Samsung Galaxy A06"

normaliseSpecsFromSpecRows(rows) — handles all structured key/value sources:

  Key normalisation: key.toLowerCase().replace(/[\s/\-_().]/g, '')
  Handled keys (among others):
    processor / cpu / processormodel         → specs.cpu (normalised casing)
    processormodelnumber / cpumodelnumber    → IC composite CPU number
    graphics / gpu / videoprocessor etc.     → specs.gpu (brand-only suppressed → infer from CPU)
    ram / memory / ramcapacity etc.          → specs.ramGb + ramType
    ramtype / memorytype                     → specs.ramType
    ramspeed / memoryfrequency               → specs.ramSpeed
    storage / internalstorage / ssdcapacity
      / memorystoragecapacity / flashmemorysize → specs.storageGb + storageType
    harddiskdescription / harddisktype       → specs.storageType only
    storagetechnology / storagetype          → specs.storageType
    display / screen                         → specs.display
    resolution / screenresolution            → appended to display
    displaytechnology / paneltype            → appended to display
    operatingsystem / os                     → specs.operatingSystem (iOS + Android included)
    battery / batterycapacity                → specs.battery (suspicious <1000mAh flagged)
    weight / netweight / itemweight          → specs.weight
    warranty / warrantyperiod                → specs.warranty
    usbtypec / usbc                          → specs.ports
    usb3 / usb30 / usb32                    → specs.ports
    hdmi / hdmiout                           → specs.ports
    wifi / builtinwifi                       → specs.connectivity
    bluetooth                                → specs.connectivity
    connectivitytechnology / wirelesstechnology → specs.connectivity (full value, comma list)
    cellulartechnology                       → prepended to connectivity
    camera / webcam / cameraresolution       → specs.camera
    displaybrightness / brightness           → specs.brightness

  IC composite CPU: "Processor: AMD Ryzen 5" + "Processor Model Number: 7520U"
    → combined to "AMD Ryzen 5 7520U" at end of loop

  CPU casing normalisation: amd→AMD, ryzen→Ryzen, intel→Intel, core→Core,
    apple→Apple, mediatek→MediaTek, snapdragon→Snapdragon, exynos→Exynos, helio→Helio

normaliseSpecsFromTitle(title):
  RAM: "16GB RAM" / "16GB DDR5" / "8GB LPDDR5"
  Storage: "512GB SSD" / "1TB NVMe" / "256GB HDD"
  CPU: 22 patterns covering all PC + mobile chip families
       includes bare family names (no AMD/Intel prefix) for URL slug compatibility
  RAM fallback: bare "16GB" for known sizes (4/6/8/10/12/16/24/32/48/64) when
    no strict match found and value doesn't conflict with already-found storage
  Phone storage fallback: 128/256/512/1024 GB without SSD suffix
  Display: size from "15.6-inch" / "6.7"" / "15.6 FHD" patterns
  OS: Windows 10/11 (Home/Pro/S), macOS, iOS, Android; bare "Windows" captured

  "win11pro" / "win11home" / "win-11-home" → "Windows 11 Pro" / "Windows 11 Home"
  "m 2" → "M.2"
  CPU numbers: "7520u" → "7520U"
  Brands: hp→HP, dell→Dell, lenovo→Lenovo, asus→ASUS, samsung→Samsung,
    xiaomi→Xiaomi, huawei→Huawei, oppo→OPPO, realme→Realme
  Phone models: iphone→iPhone, ipad→iPad, galaxy→Galaxy, pixel→Pixel,
